# Flappy Bird Clone

A simple clone of the game Flappy Bird in [MonoGame](https://monogame.net/). This project is a nonprofit initiative. 

## How to play the game
### Keys
```fish
Space => jump
R => Reload Game when player is died
```

## How to compile

### In DotnetCore(Linux, Mac and Windows)
#### 1) Clone repo
```fish
git clone https://github.com/PauloEduardoSilva15/Flappy.git
```
#### 2) Open the project
```fish
cd ./Flappy
```
#### 3) Running the project
```fish
dotnet run
```
